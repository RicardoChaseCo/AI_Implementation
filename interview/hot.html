1 两数之和

Two Sum · Easy

给定整数数组 nums 和目标 target。找出和为 target 的两个下标，每个下标只用一次。

例：nums = [2, 7, 11, 15]，target = 9 → [0, 1]

fun twoSum(nums: IntArray, target: Int): IntArray {
    val map = HashMap<Int, Int>()

    for (i in nums.indices) {
        val x = nums[i]
        val need = target - x

        val found = map[need]
        if (found != null) {
            return intArrayOf(found, i)
        }

        map[x] = i
    }

    return intArrayOf()
}

217 存在重复元素

Contains Duplicate · Easy

判断数组里有没有重复出现的数字。

例：nums = [1, 2, 3, 1] → true。nums = [1, 2, 3, 4] → false

fun containsDuplicate(nums: IntArray): Boolean {
    val seen = HashSet<Int>()

    for (i in nums.indices) {
        val x = nums[i]

        if (seen.contains(x)) {
            return true
        }

        seen.add(x)
    }

    return false
}

219 存在重复元素 II

Contains Duplicate II · Easy

判断是否存在两个相等的数字，它们的下标差不超过 k。

例：nums = [1, 2, 3, 1]，k = 3 → true。nums = [1, 2, 3, 1, 2, 3]，k = 2 → false

fun containsNearbyDuplicate(nums: IntArray, k: Int): Boolean {
    val map = HashMap<Int, Int>()

    for (i in nums.indices) {
        val x = nums[i]
        val found = map[x]

        if (found != null && i - found <= k) {
            return true
        }

        map[x] = i
    }

    return false
}

202 快乐数

Happy Number · Easy

把一个数换成各位数字的平方和，一直做下去。能变成 1 就是快乐数，数字开始循环就不是。

例：n = 19 → true。19 → 82 → 68 → 100 → 1

fun isHappy(n: Int): Boolean {
    val seen = HashSet<Int>()
    var x = n

    while (x != 1) {
        if (seen.contains(x)) {
            return false
        }
        seen.add(x)

        var sum = 0
        var y = x
        while (y > 0) {
            val digit = y % 10
            sum = sum + digit * digit
            y = y / 10
        }
        x = sum
    }

    return true
}

205 同构字符串

Isomorphic Strings · Easy

s 和 t 等长。s 的每个字符要固定换成 t 的同一个字符，不同字符不能换成同一个。

例：s = "egg"，t = "add" → true。s = "foo"，t = "bar" → false

fun isIsomorphic(s: String, t: String): Boolean {
    if (s.length != t.length) {
        return false
    }

    val sToT = HashMap<Char, Char>()
    val tToS = HashMap<Char, Char>()

    for (i in s.indices) {
        val a = s[i]
        val b = t[i]

        val aMapped = sToT[a]
        if (aMapped != null && aMapped != b) {
            return false
        }

        val bMapped = tToS[b]
        if (bMapped != null && bMapped != a) {
            return false
        }

        sToT[a] = b
        tToS[b] = a
    }

    return true
}

290 单词规律

Word Pattern · Easy

pattern 里的每个字母对应 s 里的一个单词，字母和单词要一一对应。

例：pattern = "abba"，s = "dog cat cat dog" → true。s = "dog cat cat fish" → false

fun wordPattern(pattern: String, s: String): Boolean {
    val words = s.split(" ")
    if (pattern.length != words.size) {
        return false
    }

    val pToW = HashMap<Char, String>()
    val wToP = HashMap<String, Char>()

    for (i in pattern.indices) {
        val a = pattern[i]
        val b = words[i]

        val aMapped = pToW[a]
        if (aMapped != null && aMapped != b) {
            return false
        }

        val bMapped = wToP[b]
        if (bMapped != null && bMapped != a) {
            return false
        }

        pToW[a] = b
        wToP[b] = a
    }

    return true
}

383 赎金信

Ransom Note · Easy

赎金信里每个字母的出现次数，都不能超过杂志里这个字母的次数。

例：ransomNote = "aa"，magazine = "aab" → true。magazine = "ab" → false

fun canConstruct(ransomNote: String, magazine: String): Boolean {
    val count = HashMap<Char, Int>()

    for (ch in magazine) {
        val old = count[ch] ?: 0
        count[ch] = old + 1
    }

    for (ch in ransomNote) {
        val old = count[ch] ?: 0
        if (old == 0) {
            return false
        }
        count[ch] = old - 1
    }

    return true
}

242 有效的字母异位词

Valid Anagram · Easy

fun isAnagram(s: String, t: String): Boolean {
    if (s.length != t.length) {
        return false
    }

    val count = HashMap<Char, Int>()

    for (ch in s) {
        val old = count[ch] ?: 0
        count[ch] = old + 1
    }

    for (ch in t) {
        val old = count[ch] ?: 0
        if (old == 0) {
            return false
        }
        count[ch] = old - 1

    return true
}

49 字母异位词分组

Group Anagrams · Medium

把互为异位词的字符串放进同一组。组的先后顺序、组内顺序都可以不同。

例：["eat","tea","tan","ate","nat","bat"] → 三组：eat/tea/ate，tan/nat，bat

fun groupAnagrams(strs: Array<String>): List<List<String>> {
    val map = HashMap<String, MutableList<String>>()

    for (s in strs) {
        val chars = s.toCharArray()
        chars.sort()
        val key = String(chars)

        var bucket = map[key]
        if (bucket == null) {
            bucket = mutableListOf()
            map[key] = bucket
        }
        bucket.add(s)
    }

    val answer = mutableListOf<List<String>>()
    for (bucket in map.values) {
        answer.add(bucket)
    }
    return answer
}

36 有效的数独

Valid Sudoku · Medium

只检查 9×9 数独里已经填上的数字。同一行、同一列、同一个 3×3 宫不能重复。'.' 是空格。

例：任一数字在它所在的行、列或宫里出现第二次 → false

fun isValidSudoku(board: Array<CharArray>): Boolean {
    val rows = Array(9) { HashSet<Char>() }
    val cols = Array(9) { HashSet<Char>() }
    val boxes = Array(9) { HashSet<Char>() }

    for (r in 0 until 9) {
        for (c in 0 until 9) {
            val ch = board[r][c]
            if (ch == '.') {
                continue
            }

            val box = (r / 3) * 3 + (c / 3)
            if (rows[r].contains(ch) || cols[c].contains(ch) || boxes[box].contains(ch)) {
                return false
            }

            rows[r].add(ch)
            cols[c].add(ch)
            boxes[box].add(ch)
        }
    }

    return true
}

128 最长连续序列

Longest Consecutive Sequence · Medium

未排序的整数数组里，数字连续的最长一段有多长。看的是数值相邻，不是下标相邻。

例：nums = [100, 4, 200, 1, 3, 2] → 4，这段是 1, 2, 3, 4

fun longestConsecutive(nums: IntArray): Int {
    val set = HashSet<Int>()
    for (x in nums) {
        set.add(x)
    }

    var best = 0

    for (x in set) {
        if (set.contains(x - 1)) {
            continue
        }

        var y = x
        var length = 1
        while (set.contains(y + 1)) {
            y = y + 1
            length = length + 1
        }

        if (length > best) {
            best = length
        }
    }

    return best
}

846 一手顺子

Hand of Straights · Medium

能不能把手里的牌分成若干组，每组恰好 groupSize 张，而且组内是连续数字。

例：hand = [1,2,3,6,2,3,4,7,8]，groupSize = 3 → true。三组是 1-2-3、2-3-4、6-7-8

fun isNStraightHand(hand: IntArray, groupSize: Int): Boolean {
    if (hand.size % groupSize != 0) {
        return false
    }

    val count = HashMap<Int, Int>()
    for (card in hand) {
        val old = count[card] ?: 0
        count[card] = old + 1
    }

    val starts = count.keys.sorted()

    for (start in starts) {
        val need = count[start] ?: 0
        if (need == 0) {
            continue
        }

        for (offset in 0 until groupSize) {
            val card = start + offset
            val have = count[card] ?: 0
            if (have < need) {
                return false
            }
            count[card] = have - need
        }
    }

    return true
}

560 和为 K 的子数组

Subarray Sum Equals K · Medium

有多少个连续子数组的和等于 k。

例：nums = [1, 1, 1]，k = 2 → 2

fun subarraySum(nums: IntArray, k: Int): Int {
    val map = HashMap<Int, Int>()
    map[0] = 1

    var prefix = 0
    var answer = 0

    for (x in nums) {
        prefix = prefix + x

        val need = prefix - k
        val found = map[need] ?: 0
        answer = answer + found

        val old = map[prefix] ?: 0
        map[prefix] = old + 1
    }

    return answer
}

437 路径总和 III

Path Sum III · Medium

二叉树里有多少条向下的路径，路径上的节点值之和等于 targetSum。不必从根出发，也不必走到叶子。

例：root = [10,5,-3,3,2,null,11,3,-2,null,1]，targetSum = 8 → 3

class TreeNode(var `val`: Int) {
    var left: TreeNode? = null
    var right: TreeNode? = null
}

fun pathSum(root: TreeNode?, targetSum: Int): Int {
    val map = HashMap<Long, Int>()
    map[0L] = 1

    fun dfs(node: TreeNode?, prefix: Long): Int {
        if (node == null) {
            return 0
        }

        val current = prefix + node.`val`.toLong()
        val need = current - targetSum.toLong()
        var answer = map[need] ?: 0

        val old = map[current] ?: 0
        map[current] = old + 1

        answer = answer + dfs(node.left, current)
        answer = answer + dfs(node.right, current)

        map[current] = old
        return answer
    }

    return dfs(root, 0L)
}

13 罗马数字转整数

Roman to Integer · Easy

把罗马数字转成整数。小的数字写在大的左边，表示用大的减去小的。

例：s = "III" → 3。s = "MCMXCIV" → 1994

fun romanToInt(s: String): Int {
    val value = HashMap<Char, Int>()
    value['I'] = 1
    value['V'] = 5
    value['X'] = 10
    value['L'] = 50
    value['C'] = 100
    value['D'] = 500
    value['M'] = 1000

    var answer = 0

    for (i in s.indices) {
        val current = value.getValue(s[i])
        val next = if (i + 1 < s.length) value.getValue(s[i + 1]) else 0

        if (current < next) {
            answer = answer - current
        } else {
            answer = answer + current
        }
    }

    return answer
}

2013 检测正方形

Detect Squares · Medium

add 把一个点加进来，同一个点可以加多次。count 返回有多少个正方形，以查询点为一个角。

例：依次 add [3,10]、[11,2]、[3,2]，再 count [11,10] → 1

class DetectSquares() {
    private val points = HashMap<Int, HashMap<Int, Int>>()

    fun add(point: IntArray) {
        val x = point[0]
        val y = point[1]

        var row = points[x]
        if (row == null) {
            row = HashMap()
            points[x] = row
        }

        val old = row[y] ?: 0
        row[y] = old + 1
    }

    fun count(point: IntArray): Int {
        val x = point[0]
        val y = point[1]
        val row = points[x]
        if (row == null) {
            return 0
        }

        var answer = 0

        for ((py, times) in row) {
            val side = y - py
            if (side == 0) {
                continue
            }

            answer = answer + square(x + side, y, py, times)
            answer = answer + square(x - side, y, py, times)
        }

        return answer
    }

    private fun square(otherX: Int, y: Int, py: Int, times: Int): Int {
        val other = points[otherX]
        if (other == null) {
            return 0
        }
        val cornerY = other[y] ?: 0
        val cornerPy = other[py] ?: 0
        return times * cornerY * cornerPy
    }
}

167 两数之和 II

Two Sum II · Medium

数组已经按非递减排好。找出和为 target 的两个下标，答案从 1 开始计数，且下标1 小于下标2。

例：numbers = [2, 7, 11, 15]，target = 9 → [1, 2]

fun twoSum(numbers: IntArray, target: Int): IntArray {
    var left = 0
    var right = numbers.lastIndex

    while (left < right) {
        val sum = numbers[left] + numbers[right]
        if (sum == target) {
            return intArrayOf(left + 1, right + 1)
        }
        if (sum < target) {
            left = left + 1
        } else {
            right = right - 1
        }
    }

    return intArrayOf()
}

11 盛最多水的容器

Container With Most Water · Medium

每条垂线的高度给在 height 里。选两条线和 x 轴围出的容器，能装下的水最多是多少。

例：height = [1, 8, 6, 2, 5, 4, 8, 3, 7] → 49

fun maxArea(height: IntArray): Int {
    var left = 0
    var right = height.lastIndex
    var best = 0

    while (left < right) {
        val width = right - left
        val high = if (height[left] < height[right]) height[left] else height[right]
        val area = width * high
        if (area > best) {
            best = area
        }

        if (height[left] <= height[right]) {
            left = left + 1
        } else {
            right = right - 1
        }
    }

    return best
}

125 验证回文串

Valid Palindrome · Easy

只看字母和数字，忽略大小写和其它字符，判断它是不是回文。

例：s = "A man, a plan, a canal: Panama" → true。s = "race a car" → false

fun isPalindrome(s: String): Boolean {
    var left = 0
    var right = s.lastIndex

    while (left < right) {
        while (left < right && !s[left].isLetterOrDigit()) {
            left = left + 1
        }
        while (left < right && !s[right].isLetterOrDigit()) {
            right = right - 1
        }

        if (s[left].lowercaseChar() != s[right].lowercaseChar()) {
            return false
        }
        left = left + 1
        right = right - 1
    }

    return true
}

15 三数之和

3Sum · Medium

找出所有和为 0 的三元组。答案里不能有重复的三元组。

例：nums = [-1, 0, 1, 2, -1, -4] → [[-1, -1, 2], [-1, 0, 1]]

fun threeSum(nums: IntArray): List<List<Int>> {
    nums.sort()
    val answer = mutableListOf<List<Int>>()

    for (i in nums.indices) {
        if (i > 0 && nums[i] == nums[i - 1]) {
            continue
        }

        var left = i + 1
        var right = nums.lastIndex
        val target = -nums[i]

        while (left < right) {
            val sum = nums[left] + nums[right]
            if (sum == target) {
                answer.add(listOf(nums[i], nums[left], nums[right]))
                left = left + 1
                right = right - 1
                while (left < right && nums[left] == nums[left - 1]) {
                    left = left + 1
                }
                while (left < right && nums[right] == nums[right + 1]) {
                    right = right - 1
                }
            } else if (sum < target) {
                left = left + 1
            } else {
                right = right - 1
            }
        }
    }

    return answer
}

240 搜索二维矩阵 II

Search a 2D Matrix II · Medium

每行从左到右递增，每列从上到下递增。判断 target 是否出现在矩阵里。

例：matrix = [[1,4,7,11,15],[2,5,8,12,19],[3,6,9,16,22],[10,13,14,17,24],[18,21,23,26,30]]，target = 5 → true。target = 20 → false

fun searchMatrix(matrix: Array<IntArray>, target: Int): Boolean {
    var row = 0
    var col = matrix[0].lastIndex

    while (row < matrix.size && col >= 0) {
        val value = matrix[row][col]
        if (value == target) {
            return true
        }
        if (value > target) {
            col = col - 1
        } else {
            row = row + 1
        }
    }

    return false
}

27 移除元素

Remove Element · Easy

fun removeElement(nums: IntArray, `val`: Int): Int {
    var slow = 0

    for (fast in nums.indices) {
        if (nums[fast] != `val`) {
            nums[slow] = nums[fast]
            slow = slow + 1
        }
    }

    return slow
}

26 删除有序数组中的重复项

fun removeDuplicates(nums: IntArray): Int {
    var slow = 0

    for (fast in nums.indices) {
        if (slow == 0 || nums[fast] != nums[slow - 1]) {

            slow = slow + 1
        }

}

    var sum = 0

fun minWindow(s: String, t: String): String {
    val need = HashMap<Char, Int>()
    for (ch in t) {
        val old = need[ch] ?: 0
        need[ch] = old + 1
    }

    val window = HashMap<Char, Int>()
    var have = 0
    val required = need.size
    var left = 0
    var bestLeft = 0
    var bestLen = Int.MAX_VALUE

    for (right in s.indices) {
        val ch = s[right]
        val old = window[ch] ?: 0
        window[ch] = old + 1
        if (need.containsKey(ch) && window[ch] == need[ch]) {
            have = have + 1
        }

        while (have == required) {
            val length = right - left + 1
            if (length < bestLen) {
                bestLen = length
                bestLeft = left
            }

            val leftCh = s[left]
            if (need.containsKey(leftCh) && window[leftCh] == need[leftCh]) {
                have = have - 1
            }
            val leftOld = window[leftCh] ?: 0
            window[leftCh] = leftOld - 1
            left = left + 1
        }
    }

    if (bestLen == Int.MAX_VALUE) {
        return ""
    }
    return s.substring(bestLeft, bestLeft + bestLen)

fun maxSlidingWindow(nums: IntArray, k: Int): IntArray {
    val deque = ArrayDeque<Int>()
    val answer = IntArray(nums.size - k + 1)
    var write = 0

    for (i in nums.indices) {
        while (deque.isNotEmpty() && deque.first() <= i - k) {
            deque.removeFirst()

            write = write + 1
        }
    }

    return answer
}

    fun set(key: String, value: String, timestamp: Int) {
        var bucket = store[key]
        if (bucket == null) {
            bucket = mutableListOf()
            store[key] = bucket
        }
        bucket.add(Pair(timestamp, value))

        val bucket = store[key]
        if (bucket == null) {
            return ""
        }

        var lo = 0
        var hi = bucket.size

            val mid = lo + (hi - lo) / 2
            if (bucket[mid].first <= timestamp) {
                lo = mid + 1
            } else {
                hi = mid
            }
        }

            return ""
        }
        return bucket[lo - 1].second
    }

    for (step in 1 until left) {
        val next = groupPrev.next
        if (next == null) {
            return dummy.next
        }
        groupPrev = next
    }

    val k = right - left + 1
    var kth: ListNode? = groupPrev

        kth = kth?.next

            return dummy.next
        }

        cur = nxt

25 K 个一组翻转链表

Reverse Nodes in k-Group · Hard

每 k 个结点一组做反转。最后不足 k 个的保持原样。

例：head = [1, 2, 3, 4, 5]，k = 2 → [2, 1, 4, 3, 5]。k = 3 → [3, 2, 1, 4, 5]

fun reverseKGroup(head: ListNode?, k: Int): ListNode? {
    val dummy = ListNode(0)
    dummy.next = head
    var groupPrev: ListNode = dummy

    while (true) {
        var kth: ListNode? = groupPrev
        for (step in 0 until k) {
            kth = kth?.next
            if (kth == null) {
                return dummy.next
            }
        }
        val end = kth ?: return dummy.next
        val groupNext = end.next
        var prev: ListNode? = groupNext
        var cur = groupPrev.next
        while (cur != null && cur != groupNext) {
            val nxt = cur.next
            cur.next = prev
            prev = cur
            cur = nxt
        }

        val nextGroupPrev = groupPrev.next
        groupPrev.next = end
        if (nextGroupPrev == null) {
            return dummy.next
        }
        groupPrev = nextGroupPrev
    }
}

        slow = slow?.next
        fast = fast.next?.next
    }

        val nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt
    }

        return
    }

    var slow = head
    var fast = head.next
    while (fast?.next != null) {
        slow = slow?.next
        fast = fast.next?.next
    }

    var cur = slow?.next
    slow?.next = null

        val nxt = cur.next
        cur.next = prev
        prev = cur
        cur = nxt

        left = leftNext
        right = rightNext
    }
}

fun mergeKLists(lists: Array<ListNode?>): ListNode? {
    val heap = java.util.PriorityQueue<ListNode>(compareBy { it.`val` })
    for (node in lists) {
        if (node != null) {
            heap.add(node)
        }
    }

    val dummy = ListNode(0)
    var tail = dummy
    while (heap.isNotEmpty()) {
        val node = heap.poll() ?: break
        tail.next = node
        tail = node
        val next = node.next
        if (next != null) {
            heap.add(next)
        }
    }
    return dummy.next
}

例：head = [1, 2, 3, 4, 5]，k = 2 → [4, 5, 1, 2, 3]

fun rotateRight(head: ListNode?, k: Int): ListNode? {
    if (head?.next == null) {
        return head
    }

    var length = 1
    var tail = head
    while (tail?.next != null) {
        tail = tail.next
        length = length + 1
    }

    val move = k % length
    if (move == 0) {
        return head
    }

    var prev = head
    for (step in 0 until length - move - 1) {
        val next = prev?.next
        if (next == null) {
            return head
        }
        prev = next
    }

    val newHead = prev?.next
    prev?.next = null
    tail?.next = head
    return newHead
}

        val x = if (a != null) a.`val` else 0
        val y = if (b != null) b.`val` else 0

            tail = next
        }
        a = a?.next
        b = b?.next
    }

fun deleteDuplicates(head: ListNode?): ListNode? {
    val dummy = ListNode(0)
    dummy.next = head
    var prev = dummy
    var cur = head

    while (cur != null) {
        val next = cur.next
        if (next != null && cur.`val` == next.`val`) {
            val value = cur.`val`
            while (cur != null && cur.`val` == value) {
                cur = cur.next
            }
            prev.next = cur
        } else {
            prev = cur
            cur = cur.next
        }
    }

    return dummy.next
}

fun partition(head: ListNode?, x: Int): ListNode? {

    val largeHead = ListNode(0)
    var small = smallHead
    var large = largeHead
    var cur = head

    while (cur != null) {
        val next = cur.next
        if (cur.`val` < x) {
            small.next = cur
            small = cur
        } else {
            large.next = cur
            large = cur
        }
        cur = next
    }

    large.next = null
    small.next = largeHead.next
    return smallHead.next
}

    var cur = head
    while (cur != null) {
        map[cur] = Node(cur.`val`)
        cur = cur.next
    }

    cur = head

        val copy = map[cur]
        if (copy != null) {
            copy.next = map[cur.next]

        }
        cur = cur.next
    }

    return map[head]
